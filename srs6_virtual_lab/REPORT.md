# СРС №6. Виртуальный стенд Arduino

## 1. Цель работы

Создать виртуальный стенд на базе Arduino UNO, подключить ультразвуковой датчик HC-SR04, три светодиода и кнопку. Проверить работу системы при различных расстояниях, воспроизвести неисправности и улучшить программу.

## 2. Используемые компоненты

- Arduino UNO;
- Ультразвуковой датчик HC-SR04;
- Красный светодиод;
- Жёлтый светодиод;
- Зелёный светодиод;
- Три резистора по 220 Ом;
- Кнопка;
- Соединительные провода.

## 3. Подключение компонентов

| Компонент | Контакт Arduino |
|---|---|
| TRIG | D9 |
| ECHO | D10 |
| Красный LED | D13 |
| Жёлтый LED | D12 |
| Зелёный LED | D11 |
| Кнопка | D2 |
| VCC датчика | 5V |
| GND датчика | GND |

Для кнопки использован режим INPUT_PULLUP.

## 4. Основные испытания

| Расстояние | Ожидаемый результат | Фактический результат |
|---|---|---|
| 10 см | Красный LED | Красный LED |
| 20 см | Жёлтый LED | Жёлтый LED |
| 35 см | Жёлтый LED | Жёлтый LED |
| 50 см | Жёлтый LED | Жёлтый LED |
| 70 см | Зелёный LED | Зелёный LED |

При отпускании кнопки все светодиоды выключаются.

## 5. Эксперимент A — неправильное назначение пина Echo

В программе контакт Echo был изменён с D10 на D8, при этом провод датчика остался подключённым к D10.

**Результат:** измерение не выполнялось, появлялось сообщение Sensor error, все светодиоды выключались.

**Вывод:** неправильное назначение контакта приводит к ошибке измерения.

## 6. Эксперимент B — отсутствие INPUT_PULLUP

В программе INPUT_PULLUP был заменён на INPUT.

**Результат:** при отпущенной кнопке жёлтый светодиод продолжал гореть.

**Причина:** вход кнопки без подтягивающего резистора может иметь неопределённое логическое состояние.

**Вывод:** для стабильной работы кнопки необходимо использовать INPUT_PULLUP или внешний подтягивающий резистор.

## 7. Программные улучшения

В итоговую программу добавлены:

1. Тайм-аут измерения pulseIn() — 30000 микросекунд.
2. Проверка отсутствия сигнала Echo. При ошибке все светодиоды выключаются.
3. Медиана трёх измерений для уменьшения влияния случайных скачков.
4. Программная фильтрация дребезга кнопки с использованием millis().

## 8. Проверка отсутствия сигнала Echo

Во время испытания провод ECHO был отсоединён от D10.

**Результат:** появилось сообщение Sensor error, светодиоды выключились.

После восстановления провода система снова работала правильно.

## 9. Ограничения виртуального моделирования

- Симулятор позволяет проверить логику программы и работу компонентов.
- Можно проверить пороговые значения расстояния.
- Можно воспроизвести неправильное назначение контактов.
- Симуляция не полностью отражает реальные электрические помехи.
- Нельзя достоверно оценить нагрев компонентов и реальные перепады напряжения.
- Поведение физической кнопки и датчика может отличаться от виртуальных моделей.

## 10. Заключение

В ходе работы был создан виртуальный стенд на Arduino UNO с датчиком HC-SR04, тремя светодиодами и кнопкой. Были проверены расстояния 10, 20, 35, 50 и 70 см. Все основные испытания прошли успешно. Также были воспроизведены две неисправности: неправильное назначение пина Echo и отсутствие INPUT_PULLUP. В программу добавлены фильтрация измерений, проверка ошибки датчика и защита от дребезга кнопки. Работа показала важность правильного подключения компонентов и безопасной обработки ошибок.
